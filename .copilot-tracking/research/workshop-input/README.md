# Workshop Input

This folder is the approved evidence root for synthetic workshop scenarios. Populate it with public or synthetic policy excerpts, SOPs, screenshots, diagrams, and related evidence that the team should review before drafting requirements or architecture.

For this session, the content is intentionally lightweight and treated as a workshop artifact rather than production evidence. Keep sensitive or regulated material out of the repository unless it is explicitly approved for a trusted environment.

## Expected content

* Policies and control references
* SOP notes or process maps
* Screenshots or application flows
* Risk and exception examples
* Questions that require human validation
